# Play Console — Content Rating Questionnaire

Fill in Play Console → **App content → Content rating**. Category: **Utility, Productivity,
Communication, or Other** (Masaya Ako fits "Social Networking / Communication" because
it has user chat + community).

## Suggested answers

| Question | Answer |
|----------|--------|
| Violence | No |
| Sexuality / nudity | No |
| Profanity / crude humor | No |
| Controlled substances | No |
| Gambling (real or simulated) | No |
| **Does the app let users interact or exchange content?** | **Yes** (chat + community feed) |
| Does the app share user-generated content? | **Yes** |
| Does the app share the user's current physical location with other users? | **Yes** (optional live map when "Share stats" is on) |
| Is the app a social/communication app? | **Yes** |
| Does the app contain ads? | **No** (unless you add them later) |

> Because the app has user-to-user communication and optional location sharing, the
> questionnaire will likely return a **Teen / PEGI 12** style rating even though your
> intended audience is adult drivers. That's expected and fine. Answer truthfully —
> misrepresenting interactivity is a common cause of rating strikes.

## Target audience & content (separate section)
- Target age group: **18+** (select the adult bracket; do not target children).
- The app is not designed for or appealing to children.
